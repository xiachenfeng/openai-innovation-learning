# OpenAI Public Innovation Timeline

Last verified: 2026-08-01

| Year | Milestone | Core public innovation |
|---|---|---|
| 2016 | Generative models | Unsupervised generative representation learning |
| 2018 | GPT-1 | Generative pretraining + supervised fine-tuning |
| 2019 | GPT-2 | Zero-shot task behavior and scaled language modeling |
| 2020 | Scaling Laws / GPT-3 | Power-law predictability and in-context few-shot learning |
| 2020-2022 | Human feedback | Reward models, PPO, RLHF |
| 2021 | CLIP / DALL·E / WebGPT / Codex | Natural-language supervision, multimodality, tools, code |
| 2022 | InstructGPT / ChatGPT / Whisper | Instruction alignment, dialogue, weakly supervised speech |
| 2023 | GPT-4 / Process Supervision | Multimodal frontier model and step-level rewards |
| 2024 | GPT-4o / o1 / CriticGPT | Native omni interaction, reasoning RL, scalable critique |
| 2025 | o3/o4, Deep Research, Codex, GPT-5, gpt-oss | Tool-integrated reasoning, agents, unified router, public MoE |
| 2026 | GPT-5.4/5.5/5.6, GPT-Red, GPT-Live | Long-horizon work, efficiency, multi-agent ultra, self-play safety, full duplex |

注意：时间线只记录公开信息，不代表完整内部研发顺序。
